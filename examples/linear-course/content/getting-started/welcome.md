# Welcome

This short course shows every schorm building block in one place:

- **Lessons** written in markdown with YAML frontmatter
- **Media** embedded with shortcodes and markdown images
- A **quiz** that gates the final lesson until you pass it
- **Linear sequencing**, so the LMS presents pages in order

Use the *Next* control in your LMS (or the links on the index page in
`schorm preview`) to continue.
